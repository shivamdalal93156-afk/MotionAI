Investigation Board II is a fully customizable After Effects project. 
Can be used as a TV program opener, as a promo for video game, board game, military openers, detective titles, investigative journalism, documentary or cinematic presentations.
Customize a range of elements like polaroid photos, documents, magazines, newspapers.



Compatible with After Effects CS5.5 and above
Full HD Resolution (1920×1080)
No Plugin Required
Works with any language “Universal Expressions”
19 Placeholders for Content
19+ Placeholders for Text
Video Tutorial included
PDF Tutorial included
Pictures are not included
This project contains all the images, except photos from the video preview
